## Objective
The purpose of this assignment is to practice HTML structure, text formatting, lists, images, links, tables, forms, and CSS styling. The project also demonstrates selectors, classes and IDs, the box model, positioning, sizing units, float/clear, and a favicon.

## Project Files
- `index.html` — main webpage containing all required HTML tasks.
- `style.css` — external CSS stylesheet.
- `assets/profile.svg` — local profile image used with the `<img>` tag.
- `assets/favicon.png` — website favicon.

## Part 1 — Introduction to HTML

### Step 0 — HTML Boilerplate
Created `index.html` with `<!DOCTYPE html>`, `<html>`, `<head>`, `<title>`, and `<body>`. The page title is **My First Webpage**.

### Step 1 — Text Structure
Used `<h1>`, `<h2>`, and paragraph elements to structure the webpage and introduce the student.

### Step 2 — HTML Lists
Created an ordered list of hobbies and an unordered list of favorite websites.

### Step 3 — Images and Links
Added a local profile image using `<img>` and clickable links to YouTube, GitHub, and W3Schools.

### Step 4 — HTML Button
Added a **Click Me** button. No JavaScript functionality is required for this task.

## Part 2 — Intermediate HTML

### Step 5 — Table
Created a three-column weekly schedule with **Subject**, **Day**, and **Time**.

### Step 6 — Table Layout
The optional table-based layout challenge was not required; the main page uses semantic `<div>` sections instead.

### Step 7 — Emojis
Added three emojis to a paragraph describing the mood of the day: 😎 🚀 😊.

### Step 8 — HTML Form
Created a form containing Name, Email, Favorite Color, and Submit fields.

## Part 3 — Introduction to CSS

### Step 9 — CSS Styling
Added CSS styling to the existing HTML page.

### Step 10 — Inline CSS
The first About Me paragraph uses an inline `style` attribute to change its text color.

### Step 11 — Internal CSS
The `<head>` contains a `<style>` block with rules for headings and an internal-note paragraph.

### Step 12 — External CSS
Created `style.css` and connected it to `index.html` with `<link rel="stylesheet" href="style.css">`.

### Step 13 — CSS Selectors
The project demonstrates:
- Element selectors such as `body`, `h2`, `p`, and `button`.
- Class selectors such as `.highlight` and `.content-section`.
- ID selectors such as `#main-heading`.

### Step 14 — Classes vs. IDs
The `.highlight` class is reused on multiple elements, while `#main-heading` identifies the main `<h1>` element.

## Part 4 — Intermediate CSS

### Step 15 — Favicon
Added `assets/favicon.png` and linked it in the `<head>` using the required favicon syntax.

### Step 16 — HTML Divs
Used `<div>` elements to group the header, content sections, demonstrations, and other webpage areas.

### Step 17 — Box Model
Applied borders, margins, padding, and `box-sizing` to content sections and other elements.

### Step 18 — CSS Positioning
Demonstrated `static`, `relative`, and `absolute` positioning.

### Step 19 — CSS Sizing
Used `px`, `%`, `em`, and `rem` units throughout the stylesheet for dimensions, spacing, and typography.

### Step 20 — Float and Clear
Created left and right floated boxes and used `clear: both` to prevent the following content from overlapping them.

### Step 21 — Publish Your First Website
The project is prepared for GitHub Pages. After uploading the files to a public GitHub repository, enable **Settings → Pages** and select the branch containing `index.html`.
